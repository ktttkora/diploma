## 🚨 ПРОБЛЕМЫ И РЕШЕНИЯ

### 1. Python 3.14 вместо 3.11
**Проблема:** Системный Python 3.14.7, под него нет prebuilt wheels для pydantic-core, psycopg2, pillow.
**Решение:** Пересоздан venv на Python 3.11.9 (`py -3.11 -m venv venv`).

### 2. passlib + bcrypt 5.x несовместимость
**Проблема:** `ValueError: password cannot be longer than 72 bytes` при регистрации.
**Решение:** `pip install bcrypt==4.0.1` (passlib 1.7.4 не работает с bcrypt 5.x).

### 3. Порт 5432 занят локальным PostgreSQL 18
**Проблема:** Docker PostgreSQL не мог занять порт.
**Решение:** Docker PostgreSQL переведён на **5433**, `.env` обновлён.

### 4. Асинхронный SQLAlchemy + psycopg2
**Проблема:** Изначально код был на async engine, но psycopg2 - sync драйвер.
**Решение:** Весь код переведён на sync SQLAlchemy (проще для MVP).

### 5. extra="forbid" в pydantic-settings
**Проблема:** Лишние переменные в .env (`UPLOAD_DIR`, `MAX_FILE_SIZE`) вызывали ошибку.
**Решение:** `.env` приведён в соответствие с `Settings` (`UPLOAD_FOLDER`, `TEMP_FOLDER`, `SCREENSHOTS_FOLDER`, `MAX_UPLOAD_SIZE`).

- Ревьюер: пустую или неизвестную метку при выборе одного человека нужно оставлять и помечать выбранным полом; `server_default` задавать через `sa.text("'both'")`. Обе правки внесены.
- На результате фильтр «Кто» оставляет ошибки девушки или мужчины. Тот же выбор фильтрует метки на шкале плеера. Состояние фильтра одно, на странице результата, чтобы сохранение анализа не сбрасывало список и не оставляло старые метки.
- Скриншот ошибки ищет обоих в кадре и обводит того, о ком текст. Для удара ногой берётся человек с поднятой стопой. Крупный план без рук, чтобы партнёр не попадал в кадр из-за хвата. Пояснение стоит рядом. Эталон по секунде ролика больше не подставляется: только похожая поза. Уже готовые кадры анализа 6 пересобраны.
- Скелет одного человека рисуется одним цветом: красным на кадре и зелёным на эталоне. Отдельный оранжевый цвет для рук или корпуса убран. Кадры анализа 6 пересобраны.
- На рол-ауте 16.59 с оба прохода pose solution садились на мужчину, и карточка девушки обводила его. Скриншот дополнительно берёт `pose_landmarker_lite` (до двух человек) и оставляет позу, если грудь другого цвета. Светлая грудь — девушка, тёмная — мужчина; это решается раньше стойки и удара.
