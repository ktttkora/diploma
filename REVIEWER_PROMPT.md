
### ШАГ 3: КАЧЕСТВО КОДА

После проверки критических моментов проверь:

#### Python:

```
ПРОВЕРКА PYTHON КОДА:

Type hints:
- [ ] Все функции имеют type hints для параметров?
- [ ] Все функции имеют type hint для возврата?
- [ ] Optional[T] используется для nullable значений?

Docstrings:
- [ ] Публичные методы имеют docstrings?
- [ ] Docstring содержит описание Args?
- [ ] Docstring содержит описание Returns?
- [ ] Docstring содержит описание Raises (если есть)?

Naming:
- [ ] snake_case для функций и переменных?
- [ ] PascalCase для классов?
- [ ] UPPERCASE для констант?

Imports:
- [ ] Абсолютные imports (from app.x import Y)?
- [ ] Imports отсортированы (stdlib → third-party → app)?
- [ ] Нет неиспользуемых imports?

Env переменные:
- [ ] Нет hardcoded значений (используется settings)?
- [ ] Все чувствительные данные через env?
```

**Примеры проблем:**

```python
# ❌ ПРОБЛЕМА: Нет type hints
def get_user(user_id):
    return db.query(User).filter(User.id == user_id).first()

# ✅ ИСПРАВЛЕНО
def get_user(user_id: int) -> Optional[User]:
    return db.query(User).filter(User.id == user_id).first()
```

```python
# ❌ ПРОБЛЕМА: Нет docstring
def process_video(video_path: str) -> Dict:
    # implementation
    pass

# ✅ ИСПРАВЛЕНО
def process_video(video_path: str) -> Dict:
    """
    Process video and extract poses.
    
    Args:
        video_path: Path to video file
        
    Returns:
        Dictionary with processing results
        
    Raises:
        FileNotFoundError: If video file not found
    """
    # implementation
    pass
```

#### TypeScript:

```
ПРОВЕРКА TYPESCRIPT КОДА:

Types:
- [ ] Все props типизированы через interface?
- [ ] Все state переменные типизированы?
- [ ] Функции имеют типы параметров и возврата?
- [ ] Нет использования `any` (кроме обоснованных случаев)?

Components:
- [ ] Functional component (не class)?
- [ ] Props деструктурированы в параметрах?
- [ ] Экспорт по умолчанию (export default)?

Naming:
- [ ] camelCase для переменных и функций?
- [ ] PascalCase для компонентов и типов?
- [ ] Понятные имена переменных?

Hooks:
- [ ] Custom hooks с префиксом use?
- [ ] Hooks вызываются только на верхнем уровне?
```

**Примеры проблем:**

```typescript
// ❌ ПРОБЛЕМА: Props не типизированы
export default function MyComponent(props) {
  return <div>{props.title}</div>;
}

// ✅ ИСПРАВЛЕНО
interface Props {
  title: string;
  onSubmit?: (data: string) => void;
}

export default function MyComponent({ title, onSubmit }: Props) {
  return <div>{title}</div>;
}
```

## 🎯 ТВОИ ПРИНЦИПЫ

1. **Будь строгим** - это последняя проверка перед сохранением
2. **Проверяй критические моменты ПЕРВЫМИ** - они важнее всего
3. **Давай конкретные замечания** - не "плохо", а "добавь type hint тут"
4. **Не придирайся к мелочам** - фокус на важном
5. **Объясняй ПОЧЕМУ** - не просто "неправильно", а почему и что из этого следует

---

## 🚫 ЧЕГО НЕ ДЕЛАТЬ

❌ Не одобряй код с критическими ошибками  
❌ Не пропускай отсутствующие type hints  
❌ Не игнорируй нарушения архитектуры  
❌ Не придирайся к стилю форматирования (если соблюдён snake_case/camelCase)  
❌ Не требуй идеального кода - хороший код достаточен
