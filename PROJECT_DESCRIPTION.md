# Описание дипломного проекта

## Название проекта
**Веб-сервис для анализа техники танца хастл с использованием искусственного интеллекта**

---

## 1. Цель проекта

Создать веб-приложение, которое автоматически анализирует технику исполнения танца хастл по загруженному видео и предоставляет танцорам детальную обратную связь с указанием ошибок и рекомендациями по улучшению.

---

## 2. Целевая аудитория

- **Основная**: Любители танцев хастл (начинающие танцоры)
- **Дополнительная**: Продвинутые танцоры для самоконтроля и совершенствования техники
- **Без системы уровней**: анализ одинаковый для всех, объективный

---

## 3. Основной сценарий использования

1. Пользователь загружает видео своего танца (solo или с партнером)
2. Система анализирует видео с помощью AI
3. Пользователь получает результат в виде:
   - **Скриншотов** с выделенными проблемными моментами
   - **Временных меток** (на какой секунде обнаружена ошибка)
   - **Текстовых описаний** ошибок и рекомендаций

---

## 4. Критерии анализа (по приоритету)

### 4.1. Ритм (наивысший приоритет)
- **Попадание шага в бит музыки**
- Анализ:
  - Извлечение аудио из видео
  - Определение битов музыки (beat tracking)
  - Определение моментов шагов танцора
  - Сопоставление шагов с битами

### 4.2. Постура (осанка)
- **Сохранение ровной осанки**
- Не ломать постуру при движении
- Анализ положения позвоночника, плеч, головы

### 4.3. Контент (правильность выполнения движений)
- **Корректное выполнение танцевальных элементов**
- Распознавание конкретных фигур хастла
- Сравнение с эталонными движениями из датасета

### 4.4. Музыкальность
- **Соответствие движений характеру музыки**
- При активных битах — активные движения
- При затяжной музыке — плавные, затянутые движения
- Смена движений на смену музыкальных квадратов

## 6. Технологический стек (рекомендуемый)

### 6.1. Backend
- **Язык**: Python 3.10+
- **Фреймворк**: FastAPI
  - Быстрый, современный
  - Асинхронный
  - Автоматическая документация API (Swagger)
  - Отлично подходит для ML-задач

### 6.2. AI/ML компоненты

#### Внешний AI API (основной анализ)
- **Подключение к внешней нейросети через API**
  - Анализ техники танца
  - Распознавание движений
  - Оценка качества исполнения
  - Детекция ошибок
  
**Варианты API для рассмотрения**:
- Собственная обученная модель на внешнем сервере
- Claude API (Anthropic) — мультимодальный анализ видео
- OpenAI GPT-4 Vision
- Google Gemini Vision
- Специализированные ML-as-a-Service платформы

#### Локальная предобработка

**Анализ позы (Pose Estimation)**
- **MediaPipe Pose** (Google)
  - Извлечение ключевых точек тела
  - Предобработка для API
  - Локальная визуализация

**Анализ аудио**
- **librosa** — анализ музыки
  - Beat tracking (определение битов)
  - Tempo detection (BPM)
  - Onset detection (начало звуков)
  - Извлечение признаков для передачи в API

**Компьютерное зрение**
- **OpenCV** — обработка видео
  - Извлечение кадров
  - Предобработка
  - Сжатие для отправки в API
  - Наложение визуализации на результаты

### 6.3. Frontend
- **React** + **TypeScript**
  - Современный, популярный
  - Компонентный подход
  - Богатая экосистема

- **UI библиотеки**:
  - Material-UI (MUI) или Ant Design
  - React Player для видео
  - React Dropzone для загрузки файлов

### 6.4. База данных
- **PostgreSQL**
  - Надежная
  - Поддержка JSON для хранения результатов анализа
  - Хорошая интеграция с Python

### 6.5. Хранилище файлов
- **Локально**: для разработки
- **Cloud** (опционально): AWS S3 / Google Cloud Storage / Яндекс.Облако

### 6.6. Дополнительные инструменты
- **FFmpeg** — работа с видео/аудио

### 7.2. Процесс обработки

1. **Загрузка видео**
   - Пользователь загружает видео через веб-интерфейс
   - Файл сохраняется на сервере
   - Создается задача в очереди Celery

2. **Подготовка к отправке в API**
   - Валидация видео (формат, длительность, размер)
   - Конвертация в универсальный формат (MP4, H.264) если нужно

3. **Отправка в внешний AI API**
   - Полное видео отправляется в AI API без сжатия
   - Сохранение оригинального FPS и разрешения для точного анализа ритма
   - API получает видео целиком для анализа

4. **Обработка в AI API**
   - **Анализ ритма**: 
     - Извлечение аудио и определение битов
     - Анализ видео для определения моментов шагов
     - Сопоставление шагов с битами (точность до долей секунды)
   - **Анализ постуры**:
     - Определение поз (pose estimation)
     - Проверка выравнивания позвоночника, плеч, головы
     - Детекция "сломанной" осанки
   - **Анализ техники движений**:
     - Распознавание элементов хастла
     - Сравнение с эталонными движениями
     - Оценка правильности выполнения
   - **Анализ музыкальности**:
     - Соответствие движений характеру музыки
     - Активность в активных частях, плавность в медленных
     - Акценты на смену музыкальных квадратов
   - **Детекция ошибок**:
     - Формирование списка ошибок с точными временными метками
     - Категоризация (ритм, постура, техника, музыкальность)
     - Оценка серьезности (критичная, средняя, легкая)
   - **Генерация рекомендаций**:
     - Текстовое описание каждой ошибки
     - Конкретные советы по исправлению

5. **Обработка результатов от AI**
   - Получение JSON с ошибками от API
   - Извлечение кадров из оригинального видео для каждой ошибки
   - Наложение визуальных маркеров:
     - Скелет (ключевые точки тела)
     - Стрелки и подсветка проблемных зон
     - Сравнение "Как есть" vs "Как надо"
   - Сохранение скриншотов и данных в БД

6. **Отправка результата**
   - Уведомление пользователя о завершении
   - Отображение результатов в UI

## 9. Основные функции веб-интерфейса

### 9.1. Главная страница (без авторизации)
- Описание сервиса
- Демо-видео или примеры анализа
- Кнопки "Войти" / "Регистрация"

### 9.2. Регистрация / Авторизация
- **Регистрация**: Email + Пароль + Подтверждение пароля
- **Авторизация**: Email + Пароль
- Восстановление пароля через email
- Подтверждение email (опционально для MVP)

### 9.3. Личный кабинет
- **Профиль пользователя**:
  - Имя (редактируемое)
  - Email (показывается, изменение через подтверждение)
  - Фото профиля (загрузка/изменение)
  - Смена пароля
- **История анализов**:
  - Список всех сохраненных видео
  - Дата загрузки
  - Превью видео (thumbnail)
  - Краткая статистика по каждому (количество ошибок, общая оценка)
  - Клик → открывает полный результат анализа
- **Статистика прогресса**:
  - **График по категориям** — как меняются оценки ритма, постуры, техники, музыкальности со временем (отдельные линии)
  - **Топ-3 частых ошибки** — какие ошибки повторяются чаще всего у пользователя

### 9.4. Страница загрузки видео
- Drag & drop или выбор файла
- Поддерживаемые форматы: MP4, AVI, MOV
- Ограничения: до 10 минут, до 1 GB
- Прогресс загрузки
- Кнопка "Разобрать"

### 9.5. Страница обработки
- Статус обработки ("Извлечение аудио", "Анализ позы", "Анализ ритма", "Генерация отчета")
- Прогресс-бар
- Примерное время ожидания
- Возможность отменить анализ

### 9.6. Страница результатов
- **Вверху**: Видеоплеер с оригинальным видео
- **Внизу**: Вертикальная лента скриншотов с ошибками
  - Каждый блок содержит:
    - Скриншот с визуальной разметкой
    - Сравнение "Как есть" ❌ / "Как надо" ✅
    - Временная метка (например, "00:05.3")
    - Текстовое описание ошибки
    - Рекомендация по исправлению
  - Скриншоты идут сверху вниз в хронологическом порядке
  - При клике на скриншот — видео перематывается на эту секунду
- **Дополнительно**:
  - Общая оценка и статистика
  - **Выбор действия**:
    - ✅ "Сохранить в историю" — результат появится в личном кабинете
    - ❌ "Не сохранять" — видео и результаты удаляются, можно сразу загрузить новое
  - Кнопка "Проанализировать другое видео"
