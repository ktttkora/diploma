# Промпт для тестирования AI моделей на анализе видео танца хастл

## Инструкция по использованию

1. Выбери **короткое тестовое видео** из датасета (30-60 секунд, чтобы быстрее и дешевле)
2. Используй этот промпт с разными моделями:
   - **Google Gemini 2.0 Flash** (рекомендую)
   - **Claude Sonnet 5.5** (новая версия, claude-sonnet-5-5)
   - **OpenAI GPT-4o**
3. Сравни результаты по критериям:
   - ✅ Точность анализа ритма
   - ✅ Точность анализа постуры
   - ✅ Качество описания ошибок
   - ✅ Адекватность временных меток
   - ✅ Полезность рекомендаций
   - 💰 Стоимость обработки
   - ⏱️ Скорость ответа

---

## Промпт (скопируй целиком)

```
Ты — профессиональный тренер по танцам хастл. Проанализируй это видео танца по четырём критериям.

### Критерии анализа (по приоритету):

1. **Ритм** (самое важное)
   - Попадают ли шаги танцора точно в биты музыки
   - Есть ли опоздания или опережения
   - Насколько стабильно держится ритм

2. **Постура** (осанка)
   - Ровная ли спина (позвоночник выпрямлен)
   - Не ломается ли корпус вперёд/назад/в стороны
   - Положение головы, плеч, таза

3. **Техника движений**
   - Правильность выполнения элементов хастла
   - Чёткость движений
   - Координация рук и ног

4. **Музыкальность**
   - Соответствие характера движений характеру музыки
   - Акценты на смену музыкальных фраз
   - Активность в активных частях, плавность в медленных

---

### Формат ответа (СТРОГО JSON):

Верни **только валидный JSON** без дополнительного текста до или после.

```json
{
  "video_duration_seconds": <длительность видео>,
  "overall_score": <общая оценка от 0 до 10>,
  "scores": {
    "rhythm": <оценка 0-10>,
    "posture": <оценка 0-10>,
    "technique": <оценка 0-10>,
    "musicality": <оценка 0-10>
  },
  "errors": [
    {
      "timestamp": <секунда, например 5.3>,
      "category": "rhythm | posture | technique | musicality",
      "severity": "high | medium | low",
      "description": "Краткое описание ошибки (1-2 предложения)",
      "recommendation": "Конкретная рекомендация как исправить"
    }
  ],
  "summary": "Общее резюме анализа (2-3 предложения)"
}
```

**Важно:**
- Указывай **точные временные метки** (в секундах с точностью до 0.1 сек)
- Описания ошибок должны быть **конкретными**, не общими фразами
- Рекомендации должны быть **применимыми** на практике
- Найди **минимум 3-5 ошибок** (если видео не идеальное)
- Категоризируй ошибки по **severity**: high (критичная), medium (средняя), low (лёгкая)

---

### Примеры хороших описаний ошибок:

✅ **Хорошо:**
- "Шаг правой ногой опоздал на бит на ~0.2 секунды"
- "Корпус наклонён вперёд на ~15 градусов, нарушена вертикаль"
- "Рука не полностью выпрямлена при выходе в Американку"

❌ **Плохо:**
- "Проблемы с ритмом"
- "Осанка неправильная"
- "Движение выполнено некорректно"
```

## Как тестировать модели

### 1. Google Gemini 2.0 Flash

**Способ 1: Google AI Studio (бесплатно для тестов)**
1. Открой https://aistudio.google.com/
2. Создай новый prompt
3. Загрузи видео
4. Вставь промпт выше
5. Запусти

**Способ 2: Python API**
```python
import google.generativeai as genai

genai.configure(api_key="YOUR_API_KEY")
model = genai.GenerativeModel('gemini-2.0-flash-exp')

# Загрузи видео
video_file = genai.upload_file("path/to/test_video.mp4")

# Вставь промпт
prompt = """<промпт выше>"""

response = model.generate_content([prompt, video_file])
print(response.text)
```

### 2. Claude 3.5 Sonnet (Anthropic)

**Ограничение:** Claude не принимает видео напрямую, нужно отправить **кадры**.

**Подготовка кадров:**
```python
import cv2
import base64
import anthropic

# Извлеки 50-100 кадров из видео
def extract_frames(video_path, num_frames=50):
    cap = cv2.VideoCapture(video_path)
    total_frames = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    step = total_frames // num_frames
    
    frames = []
    for i in range(0, total_frames, step):
        cap.set(cv2.CAP_PROP_POS_FRAMES, i)
        ret, frame = cap.read()
        if ret:
            _, buffer = cv2.imencode('.jpg', frame)
            frames.append(base64.b64encode(buffer).decode('utf-8'))
    
    cap.release()
    return frames

frames = extract_frames("test_video.mp4", num_frames=50)

# Отправь в Claude
client = anthropic.Anthropic(api_key="YOUR_API_KEY")

message = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=4096,
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "<промпт выше>"},
            *[{"type": "image", "source": {"type": "base64", "media_type": "image/jpeg", "data": frame}} for frame in frames]
        ]
    }]
)

print(message.content[0].text)
```

### 3. OpenAI GPT-4o

**Способ 1: Playground (платно)**
1. Открой https://platform.openai.com/playground
2. Выбери модель `gpt-4o`
3. Загрузи видео (если поддерживается) или кадры

**Способ 2: Python API**
```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_API_KEY")

# GPT-4o может принимать видео через URL или base64
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{
        "role": "user",
        "content": [
            {"type": "text", "text": "<промпт выше>"},
            {"type": "video", "video": "<video_url_or_base64>"}
        ]
    }]
)

print(response.choices[0].message.content)
```

## Какое видео выбрать для теста

Рекомендую взять **короткое видео (30-60 сек)** с:
- ✅ Явными ошибками (чтобы проверить, найдёт ли модель)
- ✅ Чётким звуком музыки (для анализа ритма)
- ✅ Хорошим освещением (чтобы модель видела позу)
- ✅ Полным кадром танцора (не обрезанный)

**Пример из твоего датасета:**
Возьми любое видео из `hasl_files/`, где танцор делает базовый элемент.
